# 知识树画布

知识树画布是一个用于整理学习路径的可视化知识关系工具。它把每个知识点表示成可拖动的节点，用连线表达前置知识、后置知识、母子层级和相关关系，让用户可以围绕当前知识点逐层组织自己的知识结构。

## 核心功能

- 知识树管理：按领域创建不同知识树，例如人工智能、文学、音乐。
- 节点画布：每个知识点都是一个可拖动的小方块节点。
- 横向关系：展示当前节点的前置节点、当前节点、后置节点和未连接的独立节点。
- 纵向层级：点击节点后展示它的母节点、当前节点和子节点。
- 节点连接：通过拖拽连线建立前置、后置、母子或相关关系。
- 节点编辑：在资料卡中编辑标题、学习状态和简介。
- 资源链接：为节点添加“我的笔记”和“外部资源”链接。
- 右键菜单：支持树集复制、重命名、删除；支持节点新增前置、后置和删除子树；支持资源链接删除。
- 画布操作：支持节点拖动、画布平移和滚轮缩放。
- 数据交换：支持 JSON 导入导出，方便分享或迁移知识树。

## 设计原则

- 知识正文不放在应用里，只保存简介和资源链接。
- 横向关系和纵向层级分开查看，避免整棵树一次性铺满画布。
- 数据结构保持轻量和标准化，便于后续接入 AI 自动整理节点。
